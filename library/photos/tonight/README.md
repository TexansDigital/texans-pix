# Tonight

Frames filed **during a game**. They appear in the Tonight shelf above the
season library, newest first, and clear with `npm run archive` after the
whistle.

Name the file after the moment, or drop a `.txt` sidecar with the caption:

    q3-stroud-42yd-td.jpg
    q3-stroud-42yd-td.txt   ->  Q3 // STROUD 42 YD TD // HOU 21 IND 14

**Real frames only.** Anything in here ships to a public, Texans-branded page
with its caption presented as fact. Never use a placeholder, a test image, or
an invented score — a fabricated play attributed to a real player is the one
thing this folder must never publish.
